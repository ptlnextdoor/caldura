# Caldura

Caldura is a sales request intake demo for fastener and MRO catalog workflows.

The demo shows how a sales team can turn messy customer requests and RFQs into structured line items, candidate matches, and review decisions before a response reaches the buyer.

## Live Demo

Visit the deployed demo:

https://shanghai-gilt.vercel.app/

## What It Demonstrates

- Intake of free-form customer requests and RFQ-style text.
- Catalog-aware matching for fastener and MRO items.
- Confidence and validation gates that route uncertain requests to sales review.
- Demo customer context for showing how previous buying patterns can influence recommendations.
- Preview-only email workflow for customer confirmation drafts and internal escalation drafts.
